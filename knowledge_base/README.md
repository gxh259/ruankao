原始资料：`~/Desktop/软考【高项】2026年5月班备考资料`。索引构建于 2026-10-29。原件与提取全文仅保存在本机，不提交到公开 GitHub 仓库。

## 内容与覆盖

- 资料共 608 个有效文件，约 4.4 GB；其中 451 个 PDF、18 个 DOCX、8 个 XLSX 可尝试提取文字。
- 已处理 477 份可解析文档，其中 469 份有可检索正文，8 份只有少量或没有可提取文字；索引共 8,250 页、3,047,627 字符。PDF 原页码保存在索引中，可按关键词追溯来源。
- 另有 131 份音视频、旧 Office 格式、压缩包或图片仅编入目录，暂未转写或解包。
- 扫描版《信息系统项目管理师教程（第四版）》两份、《软考高项--考试大纲》及印刷版思维导图等基本没有可提取文字。可检索的 24 章分册讲义、知识点清单、章节练习、每日一练及案例解析可覆盖日常出题所需的大部分内容；对扫描材料的独有内容应另行核对。

## 使用

在项目根目录运行：

```bash
python3 knowledge_base/search.py '挣值分析' --limit 10
```

每条结果包含原件路径、PDF 页码和关键词附近文字。查看章节导航见 [chapters.md](chapters.md)。索引文件是 `knowledge_base/local/kb.sqlite`，该目录受 `.gitignore` 保护。若桌面资料更新，运行：

```bash
/Users/soumao/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 knowledge_base/build.py
```

若资料移动，可先设置环境变量 `RUANKAO_SOURCE` 为新目录。构建脚本会重建本地索引，包含所有可解析 PDF、DOCX、XLSX 的文字，以及其余文件的目录记录。
